## Early December

In early December my day job hit its busiest stretch. I usually hardly do any overtime, but 3-4 hours of overtime a day became the norm. Things have calmed down a bit now, but I expect some overtime through the end of the month.

It's a tough time to have at the end of the year, but I'll keep going with the New Year holidays to look forward to.

## Development Updates

### Releasing Lecture Videos

In addition to the concert videos we've been streaming on auditorium, we've now released lecture videos.

The feature itself was mostly done around September. This month I made small text fixes and spec changes, and on Friday, 12/10, we released it on both the website and the smartphone app.

App review for the smartphone app dragged on, so I was prepared for the release to slip, but we managed to release it at the same time as the website, which was a relief.

### Creating the DB Schema

As part of the move to AWS, we plan to migrate from Firebase, which we currently use, to MongoDB. Along with that, I decided to revisit the DB schema, which had gotten tangled after repeated spec changes.

The data structure wasn't that complicated to begin with, so the schema is already done.

## Plans for Late December

I'll keep moving off Firebase. Specifically, I'll migrate Firebase Authentication to AWS Cognito and Firestore to MongoDB.

For the former, I can reuse what I built for another project, so I don't expect it to take much time. For the latter, I think basic CRUD should be in sight early next month.

If anything worth mentioning comes up along the way, I'll cover it in the next post.
